# Hostel Booking System (BICT 216, Group 27)

Students book hostel rooms online; the warden manages hostels and rooms and approves or rejects bookings.
The same system is built twice:

- [`hostel_booking`](hostel_booking) - plain PHP + MySQL (XAMPP)
- [`hostel_booking_laravel`](hostel_booking_laravel) - Laravel 12 + Breeze

Setup, demo logins and where each Week 14 requirement lives: **[HOW_TO_RUN.md](HOW_TO_RUN.md)**.
